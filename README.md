# Soporte antivibración en dos etapas

Página de la presentación del tercer parcial de Vibraciones Mecánicas (Equipo Camaradas, Ingeniería Mecatrónica).

- `index.html`: portada.
- `simulaciones.html`: simulaciones interactivas, una pestaña por lámina.
- `vendor/mathjax/`: MathJax 3.2.2 para que las fórmulas se vean sin internet.

## Verla

- **En línea:** activa GitHub Pages en *Settings → Pages → Deploy from a branch → main / (root)*.
- **Sin internet:** descarga el repo y abre `index.html` en el navegador. Solo las tipografías necesitan internet; sin él se usan las del sistema.

Todos los valores son estimados y se medirán en el cuarto parcial.
